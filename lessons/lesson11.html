IF / ELSE

איך תוכנית COBOL מקבלת החלטות.

IF / ELSE — קבלת החלטות

עד עכשיו התוכניות שלנו רצו בקו ישר, שורה אחר שורה. IF הוא הצעד הראשון לקוד שמתנהג אחרת בהתאם לנתונים — ממש כמו בכל שפת תכנות אחרת.

AB
IF WS-AGE > 18
    DISPLAY "ADULT"
ELSE
    DISPLAY "MINOR"
END-IF.
IF WS-AGE &gt; 18בודק תנאי. אפשר להשתמש בסימנים (> < =) או במילים (GREATER THAN, LESS THAN).
DISPLAY "ADULT"מתבצע רק אם התנאי התקיים (TRUE).
ELSEמסמן את הענף החלופי — מה לעשות אם התנאי לא התקיים.
DISPLAY "MINOR"מתבצע רק אם התנאי לא התקיים (FALSE).
END-IF.סוגר את גוש התנאי. ב-COBOL מודרני זה חובה כדי למנוע בלבול לגבי היכן ה-IF נגמר.

ה-ELSE הוא אופציונלי — אפשר לכתוב IF בלי ELSE כלל, אם רוצים שרק יקרה משהו כשהתנאי אמיתי.

תרגיל

אם WS-AGE שווה ל-15, מה תדפיס התוכנית שלמעלה?

הצג הסבר מלא
תשובה: MINOR — כי 15 אינו גדול מ-18, אז מתבצע הענף של ה-ELSE.
