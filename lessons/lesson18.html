שיעור 18 מתוך 20

STRING / UNSTRING

חיבור ופירוק טקסטים.

STRING — חיבור טקסטים

STRING מחברת כמה חלקי טקסט (ליטרלים או משתנים) לתוך משתנה אחד — שימושי כשרוצים להרכיב הודעה או שורה שלמה מכמה מקורות.

AB
01  WS-FIRST   PIC X(10) VALUE "TOLIK".
01  WS-LAST    PIC X(10) VALUE "LEARN".
01  WS-FULL    PIC X(25).

PROCEDURE DIVISION.
    STRING WS-FIRST DELIMITED BY SPACE
           " "     DELIMITED BY SIZE
           WS-LAST DELIMITED BY SPACE
           INTO WS-FULL.
    DISPLAY WS-FULL.
STRING ... INTO WS-FULL.מחבר את כל החלקים שלמעלה לתוך WS-FULL, בסדר שבו הם מופיעים.
DELIMITED BY SPACEאומר "קח מהמשתנה רק עד הרווח הראשון" — כדי לא לגרור את הרווחים המיותרים מה-PIC X(10).
DELIMITED BY SIZEאומר "קח את כל התו הזה במלואו" — משמש לליטרלים קצרים כמו רווח בודד.

UNSTRING — פירוק טקסט

UNSTRING עושה בדיוק ההפך — מפרקת מחרוזת אחת לכמה משתנים, לפי תו מפריד (כמו פסיק).

AB
01  WS-CSV     PIC X(20) VALUE "TOLIK,LEARN,COBOL".
01  WS-PART1   PIC X(10).
01  WS-PART2   PIC X(10).
01  WS-PART3   PIC X(10).

PROCEDURE DIVISION.
    UNSTRING WS-CSV DELIMITED BY ","
        INTO WS-PART1 WS-PART2 WS-PART3.
UNSTRING WS-CSV DELIMITED BY ","מפרק את WS-CSV לפי כל פסיק שנמצא בו.
INTO WS-PART1 WS-PART2 WS-PART3כל חלק בין הפסיקים נכנס למשתנה הבא ברשימה.
