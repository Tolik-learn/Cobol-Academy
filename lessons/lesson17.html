קבצים

OPEN, READ, WRITE, CLOSE — איך COBOL עובד עם קבצים אמיתיים.

קבצים — FILE SECTION ו-OPEN/READ/WRITE/CLOSE

רוב תוכניות ה-COBOL האמיתיות בעולם לא מדפיסות למסך — הן קוראות וכותבות לקבצים (או למסדי נתונים). זה דורש הגדרות בשלוש חטיבות שונות בו-זמנית.

AB
ENVIRONMENT DIVISION.
FILE-CONTROL.
    SELECT CUSTOMER-FILE ASSIGN TO "CUSTOMERS.DAT"
        ORGANIZATION IS LINE SEQUENTIAL.

DATA DIVISION.
FILE SECTION.
FD  CUSTOMER-FILE.
01  CUSTOMER-RECORD    PIC X(50).

PROCEDURE DIVISION.
    OPEN INPUT CUSTOMER-FILE.
    READ CUSTOMER-FILE
        AT END DISPLAY "NO MORE RECORDS"
    END-READ.
    CLOSE CUSTOMER-FILE.
SELECT CUSTOMER-FILE ASSIGN TO ...מקשר שם לוגי (CUSTOMER-FILE) לקובץ פיזי בדיסק.
FD CUSTOMER-FILE.מתאר את מבנה הרשומה שבתוך הקובץ (FD = File Description).
01 CUSTOMER-RECORD PIC X(50)כל שורה בקובץ נקראת כטקסט של 50 תווים.
OPEN INPUT CUSTOMER-FILE.פותח את הקובץ לקריאה בלבד.
READ CUSTOMER-FILE ... AT END ...קורא רשומה אחת; אם הגיעו לסוף הקובץ, מבצע את מה שאחרי AT END.
CLOSE CUSTOMER-FILE.סוגר את הקובץ — חובה, גם כשמסיימים לקרוא.

שימו לב שהגדרת קובץ נוגעת בשלוש חטיבות: ENVIRONMENT (איפה הקובץ נמצא), DATA (איך רשומה בו נראית), ו-PROCEDURE (מה עושים איתו בפועל).

תרגיל

מה עלול לקרות אם מבצעים READ בלי סעיף AT END, והתוכנית מגיעה לסוף הקובץ?

הצג הסבר מלא
תשובה: בלי AT END אין דרך לתוכנית לדעת שהגיעה לסוף הקובץ בצורה מבוקרת — ברוב הקומפיילרים זה יגרום לשגיאת ריצה (abend) במקום להמשיך בצורה מסודרת.

אתגר כתיבה — סיכום החלק

סיימתם את חלק בקרת הזרימה והמבנים (שיעורים 11–17)! עכשיו נסו בעצמכם: כתבו קטע קוד שמגדיר טבלה של 5 ציונים (OCCURS), עובר עליה עם PERFORM VARYING, ומדפיס לכל ציון האם הוא "PASS" (60 ומעלה) או "FAIL".

הצג פתרון לדוגמה 
01  WS-SCORES.
    05  WS-SCORE  OCCURS 5 TIMES  PIC 9(3).
01  WS-IDX       PIC 9(1).

PROCEDURE DIVISION.
    PERFORM VARYING WS-IDX FROM 1 BY 1 UNTIL WS-IDX > 5
        IF WS-SCORE(WS-IDX) >= 60
            DISPLAY "PASS"
        ELSE
            DISPLAY "FAIL"
        END-IF
    END-PERFORM.
    STOP RUN.
