ADD

חיבור ערכים — עם ובלי GIVING.

ADD — חיבור ערכים

ל-ADD יש כמה צורות תחביר. הפשוטה ביותר מוסיפה ערך אחד ישירות לתוך משתנה קיים:

AB
01  WS-TOTAL   PIC 9(5) VALUE 100.

PROCEDURE DIVISION.
    ADD 50 TO WS-TOTAL.
    DISPLAY WS-TOTAL.
ADD 50 TO WS-TOTAL.מוסיף 50 לערך הקיים ב-WS-TOTAL. התוצאה (150) נשמרת חזרה באותו משתנה.

כשלא רוצים לשנות את המשתנים המקוריים, משתמשים ב-GIVING, שמפריד בין המקורות לתוצאה:

AB
01  WS-A       PIC 9(5) VALUE 20.
01  WS-B       PIC 9(5) VALUE 30.
01  WS-SUM     PIC 9(5).

PROCEDURE DIVISION.
    ADD WS-A WS-B GIVING WS-SUM.
    DISPLAY WS-SUM.
ADD WS-A WS-B GIVING WS-SUM.מחבר את WS-A ו-WS-B, ושם את התוצאה (50) ב-WS-SUM — בלי לשנות את WS-A או WS-B.

תרגיל

אם WS-A=20 ו-WS-B=30, מה ההבדל בין ADD WS-A TO WS-B לבין ADD WS-A WS-B GIVING WS-SUM?

הצג הסבר מלא
תשובה: הראשון משנה את WS-B עצמו לתוצאה (50) ומאבד את הערך המקורי שלו. השני משאיר את WS-A ו-WS-B ללא שינוי, ורק WS-SUM מקבל את התוצאה.
