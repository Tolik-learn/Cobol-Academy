Level 88 — שמות תנאי

לתת שם קריא לערך, במקום להשוות אליו כל פעם מחדש.

Level 88 — שמות תנאי (Condition Names)

במקום לכתוב שוב ושוב IF WS-STATUS = "A" בכל מקום בתוכנית, אפשר לתת לערך הזה שם קריא פעם אחת — עם רמה מיוחדת, 88 — ואז להשתמש בשם בכל מקום.

01  WS-STATUS       PIC X.
    88  IS-ACTIVE   VALUE "A".
    88  IS-CLOSED   VALUE "C".
88 IS-ACTIVE VALUE "A".מגדיר שם-תנאי: כשרוצים לבדוק אם WS-STATUS שווה ל-A, אפשר לכתוב IS-ACTIVE במקום.
88 IS-CLOSED VALUE "C".אותו רעיון לערך C — אפשר להגדיר כמה שמות-תנאי שרוצים תחת אותו משתנה.

עכשיו בתוך PROCEDURE DIVISION אפשר לכתוב:

IF IS-ACTIVE
    DISPLAY "ACCOUNT IS ACTIVE"
END-IF.

שימו לב כמה זה קריא יותר מ- IF WS-STATUS = "A" — ובנוסף, אם ערך הקוד משתנה בעתיד (למשל A הופך ל-01), משנים רק את ה-VALUE בהגדרה, ולא כל IF בתוכנית.

תרגיל

אם WS-STATUS שווה ל-"C", האם התנאי IS-ACTIVE יתקיים?

הצג הסבר מלא
תשובה: לא — IS-ACTIVE מוגדר רק עבור הערך "A". במקרה הזה יתקיים IS-CLOSED.
